# Future service plug-ins

Do not start new protocol plug-ins until the Lion `IMServicePlugIn` ABI is running on 10.6.

Likely experiments after that milestone:

- modernized XMPP service;
- IRC via a small helper or XMPP gateway;
- Telegram via a helper/gateway rather than embedding a modern MTProto implementation into `imagent`;
- AIM/ICQ compatibility through revival servers/gateways.
